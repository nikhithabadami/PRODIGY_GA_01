## 📖 Project Overview

This project demonstrates how to fine-tune OpenAI's GPT-2 model using the Hugging Face Transformers library. The model is trained on a custom dataset and generates coherent text based on user-provided prompts.

---

## 🎯 Objective

Train a GPT-2 language model on a custom dataset to generate meaningful and contextually relevant text.
